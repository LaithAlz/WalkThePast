# Candidate source photographs

Eight public-domain / CC0 historical photographs (all taken before 1950) for "Walk the Past".
Each file is the largest original available from the source, saved as JPEG (quality 92 where re-encoded).
Processing notes: `rome-forum-1900.jpg` was cropped to the print area to remove the Library of Congress
scanning mount and colour bars; `constantinople-eyup-street-1890.jpg` was converted from the LOC TIFF and
trimmed ~1% to remove the scan border; `kitchener-king-street-1910.jpg` was trimmed to remove the postcard
border and the printed caption strip. All others are byte-identical copies of the source file.
